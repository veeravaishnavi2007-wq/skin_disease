About the Model

State-of-the-art deep learning for dermatology

🧠

EfficientNetB2

Transfer learning on ImageNet weights, fine-tuned on 10,015 HAM10000 dermatoscopic images for optimal performance.

📊

HAM10000 Dataset

Human Against Machine dataset — 10,015 skin lesion images validated by dermatologists with histopathological ground truth.

🔬

Data Augmentation

Random rotations, flips, zoom, brightness & contrast adjustments to improve generalization and reduce overfitting.

⚖️

Class Balancing

Weighted loss function to handle the highly imbalanced dataset — critical for rare disease detection like melanoma.

🎯

Fine-Tuning

Two-stage training: freeze backbone, train head, then unfreeze top layers for domain-specific feature extraction.

📈

Performance

88-92% validation accuracy, 0.95+ ROC-AUC, with early stopping and learning rate scheduling for optimal convergence.
